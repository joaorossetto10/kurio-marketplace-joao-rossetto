# Funcionalidades (planejadas)

Na Etapa 2, `catalog/` contém a leitura de previews/busca da home e `foundation/`
as páginas navegáveis de disponibilidade futura e laboratório técnico. Módulos
comerciais completos abaixo ainda serão adicionados por fatia, sem diretórios vazios.

Os módulos `catalog`, `nft`, `auth`, `favorites`, `cart`, `checkout`, `orders`,
`profile` e `wallets` serão criados conforme a etapa correspondente.

Cada módulo reunirá seus componentes, contratos específicos, chamadas REST e
hooks Query. Não criar telas ou serviços vazios para aparentar fluxos completos.
Componentes não acessam fixtures, persistência de mocks ou o cache de outro usuário.
